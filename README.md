# Shoeb Rahman — Personal Website

Personal research portfolio of Shoeb Rahman, PhD student in Micro- and Nanoscale Systems at Louisiana Tech University, developing electrochemical sensors for heavy metal detection in water and biological samples.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole website: content, styles, and the small script that draws the voltammogram |
| `assets/headshot.jpg` | Profile photo |
| `assets/favicon.svg` | Browser-tab icon |
| `404.html` | Page shown for broken links |
| `robots.txt` | Lets search engines index the site |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

## Editing

Open `index.html` on GitHub, click the pencil icon, make the change, and click **Commit changes**. The live site updates within a minute or two.

- **Add a publication:** copy one `<li class="pub">…</li>` block in the Publications section, paste it at the top of the list, and change the text.
- **Change the photo:** upload a new image named `headshot.jpg` into `assets/`, replacing the old one (portrait shape, about 480 × 600 px).
